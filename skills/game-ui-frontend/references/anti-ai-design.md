# Anti-AI design rules

Charles Liu's 28-second reel calls out twenty recurring website design habits. The time windows below locate the examples in the recording. Treat them as prompts to inspect a real screen. The caption suggests choosing references, type and colour deliberately. For this skill, take the interaction from the bundled game studies and the visual material from the user's work. [Charles Liu's original reel](https://www.instagram.com/reel/Df-NL06GZMj/)

| In the reel | Rule for a build |
| --- | --- |
| **0–5s.** Badges under a description, an italic flourish in a headline, Instrument Serif used as a signature, and letters squeezed together. | Remove tags that merely repeat the copy. An active filter earns its chip if removing it changes the results. Honour the client's type choice. Set one real title in it at phone width and start with its native spacing. Use emphasis on the word whose meaning warrants it. |
| **5–12s.** A dashboard full of competing details, lines between every entry, pale text mixed into a paragraph, and outlines enclosing cards inside a panel. | Name the fact the visitor needs next. Give it readable contrast. Group the rest with spacing before drawing a divider or adding another shade. Keep every button visibly enclosed at rest. Static prose seldom needs its own box. Preserve focus rings and the boundaries of editable fields. |
| **12–16s.** An architecture drawing packs several nested systems into a small frame. The next example uses a whole block of copy to make one point. | For an agent service, follow one actual document from input to output. Show the handoff and open the resulting draft. Put the full architecture where an engineer can inspect it if that is part of the brief. Cut the sentences that restate what the demonstration already showed. |
| **16–19s.** A heading wears a code-comment prefix, equal sections get Roman numerals, and a tiny line above the title repeats its subject. | Name the destination once. Drop ornamental paths, section counters, and eyebrow labels. Keep a navigable location such as **Collection / Night shoots** when its parent really takes the visitor back. A numbered step earns space when the order limits what can happen next. |
| **19–23s.** A dithered sphere, a globe made of text characters, identical rounded-square icon tiles, and monospaced lettering lend unrelated products the same technical look. | Use dithering on the artwork when the studied rendering method or the client's medium calls for it. A type artist's ASCII print belongs on their wall. Let a button take its outline from the thing it operates. Reserve fixed-width type for work that benefits from alignment, such as source text or timecodes. Keep commands and fine detail legible. [PS1 rendering study](research/ps1-rendering.md) |
| **23–28s.** A small all-capitals strapline, a purple gradient filling a call-to-action panel, and full stops on a set of short titles. | Put the information that matters in legible sentence case. Take colour from the scene, material or state it represents. A stationary selection plate should still read when the lighting is flat. Use punctuation where the wording calls for it. A short menu destination usually needs only its name. |

**Try the cut.** On a photographer's board, remove the genre pill, section number, faded subtitle and border around the description. Keep the print, its name and the shaped **Inspect print** control. Open a photograph, inspect a detail, and return to the same peg by keyboard or touch. If removing a detail loses authorship, location, price, state or a way to act, restore that information where the visitor needs it. Use the same test on secondary screens.
