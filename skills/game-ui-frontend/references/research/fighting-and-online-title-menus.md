# Fighting-game entrances, mobile lobbies and a document desk

Watch where the next action becomes available. An arcade cabinet can change the wording under its logo when it receives a credit. A fighting game can move its portrait to make room for a menu. A mobile game can put the player straight into picking a starting hero. Each reveals something different about what the visitor can do on arrival.

The examples identify the build when the recording does. A moving highlight shows that selection changed. Look for the cursor crossing a control, a visible touch point or a documented input handler before attributing the change to a specific input. Each website direction is an original proposal.
