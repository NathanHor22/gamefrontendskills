# PSP control studies, Asphalt through Ridge Racer

These are the final fifty excerpts from Game Box2002’s [PSP compilation](https://www.youtube.com/watch?v=AgKACS46XII). Return to the [first hundred and inspection method](handheld-control-footage.md). Each link opens the start of the uploader’s chapter. The observations compare frames 0.5, 2.5 and 4.5 seconds into it. The cover, release and file-size caption, channel mark and hands inset belong to the video edit. The last column proposes an original website interaction.
