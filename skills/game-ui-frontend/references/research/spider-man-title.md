# From the title to a saved game in Marvel’s Spider-Man

The 2018 PS4 game keeps Peter perched against the same skyline while the player decides where to begin. The moving character identifies the world. The panel on the left tells the player which decision they are making. The 2022 PC remaster shows a visible mouse pointer. Following it reveals how a row acknowledges attention before the player decides to open it.

Gamerverse Benelux’s PC capture opens on the main menu. At 0:00.05 the pointer is near View Credits and its description is visible. By 0:00.20 the pointer has moved up to Settings, the diamond has switched rows, and the help already describes Settings. At 0:00.40 faint corner brackets are partway out. At 0:00.60 they frame a dark horizontal plate. The label stays still. The row acknowledges the pointer and updates its meaning before its decoration finishes. [Pointer and highlight, opening second](https://www.youtube.com/watch?v=n1rWpGpWH_c)

At 0:01.40 Settings is still a row. By 0:01.45 a wider panel contains the settings themselves. Peter stays in place. The pointer is already over Game in the new list, and that row develops its own highlight. At 0:03.15–0:03.50 the pointer crosses other rows and the help changes again without another panel opening. Hover can therefore be distinguished from activation. The recording shows the cursor but has no mouse-button event trace. These playheads belong to the recording. ## Applying it to a website

For a gig photographer’s archive, keep the stage photograph in view beside a short set of framed band names. On hover or keyboard focus, change the active plate immediately and preview the band in the same space. Clicking, pressing Enter or tapping once opens that band’s set. Keep the band name in place while the photograph changes. Back restores the band and focus. A direct link opens the set immediately. Use a still image and an immediate panel change for reduced motion.

The test is to move across three bands quickly, open the last, then go back. The last band should own both the preview and focus. An earlier transition must never reopen a band the visitor has already left.

A touring band's site could use the Miles Morales approach for its tour diary. Leave a single framed **Open the diary** button still while a rehearsal-room film changes from a wide shot to a close view of a marked-up setlist. Opening the diary reveals that setlist and the recording it belongs to. Use the Spider-Man 2 approach for a returning listener selecting a saved show. Keep each named show in a stable button and let the current artwork change behind the list. In either case a touch opens the chosen item directly. A still photograph can carry the same transition for reduced motion.
